TCP/IP Protocol Suite

The TCP/IP model groups network protocols into layers. Here are some commonly used examples; this list is not exhaustive.

Application layer

  • HTTP and HTTPS — web communication
  • DNS — domain name lookup
  • DHCP — automatic network configuration
  • FTP — file transfer
  • SMTP, POP3, and IMAP — email
  • SSH — secure remote access
  • SNMP — network management
  • NTP — time synchronization

Transport layer

  • TCP — reliable, ordered delivery
  • UDP — connectionless, best-effort delivery
  • SCTP — reliable message-oriented transport

Internet layer

  • IPv4 and IPv6 — addressing and packet routing
  • ICMP and ICMPv6 — network diagnostics and control
  • IGMP — IPv4 multicast group management
  • IPsec — security for IP communications

Network access layer

  • Ethernet and Wi-Fi — local network communication
  • ARP — mapping IPv4 addresses to link-layer addresses
  • PPP — point-to-point links
